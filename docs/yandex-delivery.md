# Яндекс: адрес и карта для Ижевска

Интеграция выключена по умолчанию. Ключи и тарифы не выдумываются.

В кабинете Яндекс Карт подключить JavaScript API, API Геосаджеста и API Геокодера. На сервере задать:

```
YANDEX_MAPS_ENABLED=true
YANDEX_MAPS_JS_API_KEY=...
YANDEX_MAPS_SUGGEST_API_KEY=...
YANDEX_MAPS_GEOCODER_API_KEY=...
```

JS-ключ передаётся браузеру: ограничить HTTP Referer доменами магазина и админки. Серверные ключи геосаджеста/геокодера не возвращаются клиенту. Если включены IP-ограничения этих ключей, разрешить исходящий IP API-сервера. Выбрать условия использования API, позволяющие хранить необходимую информацию об адресах заказов; бесплатность или конкретный тариф здесь не предполагаются.

Официальная документация:
- https://yandex.ru/maps-api/docs/js-api/common/quickstart.html
- https://yandex.ru/maps-api/docs/suggest-api/request.html
- https://yandex.ru/maps-api/docs/geocoder-api/request.html

API магазина:
- `GET /api/delivery/map-config`: публичный JS-ключ, признаки доступности, центр `[53.2115,56.8526]` в порядке longitude/latitude.
- `GET /api/delivery/suggest?q=...`: до шести подсказок адреса.
- `GET /api/delivery/geocode?address=...`: адрес, `{lat,lon}`, точность и вид объекта. Результат уровня улицы/района не является подтверждением конкретного дома.

Подсказки приоритизируют Ижевск; окно поиска не является зоной обслуживания. Геокодирование не подтверждает доступность доставки. Утверждённых владельцем границ и тарифов зон пока нет. Редактор полигонов и режим расчёта доступны в админке: **Профиль → Доставка** (`/delivery`), см. `docs/delivery-zones.md`. Черновики не меняют расчёт до явного переключения режима.

Сервер не логирует адреса и ключи и не кэширует ответы геокодера. Таймаут провайдера — 5 секунд. Ограничения одного API-процесса: 60 запросов на IP и 600 запросов суммарно в минуту. При масштабировании на несколько процессов нужен общий лимитер; дополнительно выставить квоты в кабинете Яндекса. Внешний reverse proxy не должен записывать query string адресных endpoint в access logs.

Проверка перед включением: реальные подсказки дома в Ижевске, соответствие точки адресу, корректное сообщение при отсутствии результатов/ошибке, мобильный браузер и Telegram, ограничения ключей и квоты. Без настроенных ключей настоящая карта/геокодирование не проверены.

## Локальные проверки 18 ноября 2026

- Unit-тесты Yandex adapter: конфигурация не раскрывает серверные ключи, отключённый провайдер не вызывается, приоритет Ижевска, разбор координат, пустой ответ и отказ провайдера.
- Nginx development/production syntax validation: прошла; адресные запросы исключены из access logs.
- Browser smoke страницы оплаты с перехваченными API-ответами, без банка: возвращение с `deliveryPayment=success` вызывает одну немедленную сверку, а не цикл запросов; новый отдельный счёт появляется после уточнения без перезагрузки страницы; просроченный незарегистрированный счёт позволяет перейти к повторной регистрации.
- На момент первых проверок ключей Яндекса не было, preview 6214 использовал старый API 6211. Позже в этот день локальный стек обновлён и начаты сквозные проверки; актуальное состояние и ограничения описаны в `docs/local-launch-verification.md`.
